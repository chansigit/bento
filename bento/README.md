## 安装与权限

1. 从 [Releases](https://github.com/chansigit/bento/releases/latest) 下载 DMG，把 Bento 拖入 **Applications** 后打开。当前安装包适用于 **Apple Silicon（arm64）**；最低声明系统版本为 macOS 11，尚未全面验证所有旧版系统。
2. 应用使用自签名证书，未经 Apple 公证。如果 macOS 阻止打开，在确认来自本仓库的前提下，按 [Apple 的说明](https://support.apple.com/en-us/102445)，到「系统设置 → 隐私与安全性」选择「仍要打开」。
3. 在同一设置页按需要授权 **`/Applications/Bento.app`**。如系统要求，退出并重新打开 Bento。

| 权限 | 用途 |
|---|---|
| 辅助功能 | Cmd+Tab 窗口切换、鼠标与触控板独立滚动方向。 |
| 屏幕录制（部分系统名为「屏幕与系统音频录制」） | 窗口缩略图、截图，以及显示 Dock 当前所在屏幕。 |
| 定位服务 | Wi-Fi 扫描时显示网络名称。 |

菜单「Bento 设置 → 通用 → 重新检查」可核对窗口切换相关权限及缩略图状态。未授权屏幕录制时，窗口切换使用应用图标；截图需要该权限。Dock 固定本身不需要辅助功能权限。

**更新前先保存重要贴图。** 贴图只在本次运行期间保留，退出或重启 Bento 会关闭。发行包沿用签名身份与 `com.sijie.gtime` Bundle ID，以延续设置和已有权限。

## 常用快捷键

| 操作 | 快捷键或手势 |
|---|---|
| 选择窗口 | 按住 ⌘，按 Tab 前进、Shift+Tab 后退；点击或松开 ⌘ 确认。 |
| 截图并生成贴图、自动复制 | ⌘1；框选时空格切换选窗口，Esc 取消。 |
| 把剪贴板图片贴到桌面 | Control + Option + P。 |
| 隐藏／显示全部贴图 | Control + Option + Shift + P。 |
| 复制／保存当前贴图 | 贴图获得焦点时，⌘C／⌘S。 |
| 移动／缩放贴图 | 拖动／双指捏合或滚轮；⌘ + 滚轮调整透明度。 |
| 关闭当前贴图 | 双击、Esc 或 ⌘W；编辑栏展开时，Esc 先收起编辑栏。 |

## 常见问题

| 遇到的情况 | 检查方法 |
|---|---|
| Cmd+Tab 仍是系统切换器 | 检查辅助功能授权与「窗口切换」启用状态；先退出 AltTab 或独立 WinTab。 |
| 应用没有打开任何窗口，只显示图标 | 这是应用入口，选中会请求重新打开；打开真实窗口后，列表会在后台刷新。 |
| 已有窗口但缩略图只有应用图标，或无法截图 | 检查屏幕录制授权是否给了 Applications 中的 Bento；列表中没有时点「＋」添加。按系统提示重启后，在「通用」重新检查。 |
| 截完粘贴的还是旧内容 | 大图需等待后台 PNG 编码。编码期间若复制了其他内容，Bento 会保留新的剪贴板内容；可点选贴图后按 ⌘C 再复制。 |
| 贴图重启后消失 | 当前没有持久历史；需要留存的图片请用 ⌘S 保存。 |
| 外接屏亮度不变 | 确认 DDC/CI 已开启、线材支持 DDC，并检查 HDR／B.I.+ 是否锁定了亮度。目前只自动匹配一台外接显示器。 |
| ⌘1 没反应 | 在「截图与贴图 → 贴图与快捷键」确认快捷键已启用，查看冲突提示；也可从菜单启动截图。系统安全输入开启时，快捷键可能暂不可用。 |

## 世界时钟

在顶栏以 12 pt 等宽数字常驻显示其他时区的当前时间；国旗与时间轻微重叠压缩间距，淡色半透明圆角底区分菜单栏背景。样式如
`🇬🇧 7:11AM⁺¹ 🇨🇳 2:11PM⁺¹`(⁺¹/⁻¹ 表示相对本地日期的跨天)。

- 按城市名搜索添加时区,支持**中文 / 英文 / 拼音**(如 `北京`、`Tokyo`、`xianggang`),
  内置 200+ 主要城市,也可直接搜任意 IANA 时区标识符
- 内置库找不到的中小城市/任意地名(如 `达姆施塔特`、`Darmstadt`、大学、地标),
  可点搜索框里的「🔍 在线搜索」用系统地图数据联网解析出所在时区(无需任何权限)
- 时间随本地时钟自动换算,自动处理夏令时;睡眠唤醒、修改系统时间/时区后立即校正

## 窗口切换

菜单「Bento 设置…」包含外观、控制、通用、例外四页；也可在「窗口切换」中启用、暂停和预览。与 Bento 同进程、同菜单栏图标，
不再启动独立 WinTab。默认启用；缺少辅助功能权限或发现独立 WinTab / AltTab 正在运行时不接管快捷键。

- 窗口按本次运行期间实际获得焦点的最近使用顺序排列；当前窗口在最前，按一次 Cmd+Tab 选上一个窗口。鼠标点击及同一应用内切换也会更新记录；打开面板期间顺序固定，后台刷新不会打乱选择。刚启动时，尚无使用记录的窗口以系统窗口顺序作为初始顺序。
- Cmd+Tab 在具体窗口间切换，Shift+Tab 反向，方向键或移动鼠标选择；点击、松开 Cmd 或 Return 确认，Esc 取消。键盘和鼠标以最后操作为准，静止的鼠标不会抢走键盘选择。
- 拖着文件时保持鼠标按住，用 Cmd+Tab 打开切换面板，将文件拖到目标缩略图上停留约 0.65 秒，或松开 Cmd，唤出窗口后再放下文件。缩略图不接收文件；直接在面板上松开鼠标会取消该次投放。移开缩略图、使用键盘或关闭面板会取消悬停计时。
- 保留紧凑的按比例缩略图布局、自动大小、最小化和隐藏窗口、无窗口应用以及应用例外。没有打开窗口的应用显示图标，选中时请求正常打开应用（例如 Preview 显示打开文件窗口、Notes 恢复主窗口）；具体行为由目标应用决定。
- 恢复窗口时读取当前最小化状态，并在激活完成后核对焦点；连续切换取消旧的重试。置顶的标准文档窗口也参与缩略图匹配。
- 「跟随 Bento」使用 Bento 的浅色/深色皮肤；也可单独指定切换器主题。
- 首次使用导入独立 WinTab 的外观和筛选设置，之后保存为 Bento 的 `windowSwitcher.*` 设置；不覆盖时钟、滚动等设置。
- **辅助功能和屏幕录制都授权给 `/Applications/Bento.app`**。独立 WinTab 的权限不能转移。
  未授权屏幕录制时使用应用图标。列表里没有 Bento 时可通过系统设置的「＋」添加。
- 设置的「通用」页显示 Bento 自身的辅助功能权限、屏幕录制权限、事件监听和真实缩略图抽样结果。点「重新检查」后按一次 Cmd+Tab 并松开，可查看是否成功聚焦目标窗口。
- 本地诊断报告位于 `~/Library/Caches/com.sijie.gtime/window-switcher-check.json`，只含权限状态、数量和切换成功标记，不含窗口标题或图像。
- 暂停会停止窗口轮询并移除键盘事件拦截，不影响滚动方向等其它功能。
- 缩略图仅在切换时读取，不写入磁盘、不上传。缩放时由 Core Graphics 转换为带明确 sRGB 配置的图像，保留透明度；切换面板使用实色背景，避免桌面颜色混入。内存保留最多 64 张缩略图，重新打开立即复用；超过 2 秒的截图在打开时异步更新，每轮切换每个窗口最多请求一次，只重绘对应卡片。已关闭窗口、暂停功能或退出应用时清理缓存。窗口列表约 2 秒刷新；跨桌面、全屏与最小化缩略图仍受应用和 macOS 的公开接口限制。

## 截图与贴图

菜单「截图与贴图」提供截图标注和剪贴板贴图，参考 [Snipaste 的截图、标注、置顶贴图流程](https://github.com/Snipaste/feedback/wiki/基础操作)，与 Bento 同进程运行。

- **⌘1**：截图。拖动框选，空格切换选窗口，Esc 取消；使用 Bento 自己的选区，可在任一显示器上截图；一次选区限于当前显示器。松开鼠标后立即撤掉所有屏幕遮罩，截图按原位置、原大小成为桌面置顶贴图，可直接操作其他窗口；不自动进入标注模式。截图完成后在后台编码 PNG，完成后自动复制原始图像到剪贴板，同时保留桌面贴图；可直接到目标应用按 **⌘V** 粘贴。添加标注后按 **⌘C** 重新复制，可包含已有标注。取消截图不会覆盖剪贴板。切换到其他窗口后，⌘C 由当前窗口处理。
- 贴图下边缘默认只有「编辑」小按钮，点击展开标注工具，再点「收起」折叠菜单；直接在贴图上编辑，不打开全屏遮罩。方框、圆圈、箭头、画笔、文字、遮挡、马赛克、颜色、撤销和重做均可用，收起菜单保留标注和撤销记录。颜色下拉菜单提供八种常用色及系统自定义取色器，所选颜色用于之后绘制的标注。默认「移动」工具可拖着截图改变显示位置；触控板双指捏合或鼠标滚轮等比缩放。移动、缩放不重新截取背景，也不改变原图和标注的导出分辨率；工具栏跟随图片。
- 标注支持方框、圆圈、箭头、画笔、文字、纯黑遮挡、拖框马赛克和颜色选择；⌘Z 撤销、⌘⇧Z 重做。**⌘C** 复制、**⌘S** 保存 PNG。保存和贴图保留原像素尺寸，统一转换到 sRGB。
- **⌃⌥P**：把剪贴板里的图片贴到屏幕。贴图置顶，拖动移动，双指捏合或滚轮缩放，⌘滚轮调透明度；右键可复制、保存和恢复大小。双击、Esc 或 ⌘W 关闭（编辑菜单展开时，Esc 先收起菜单）。
- **⌃⌥⇧P**：隐藏／显示全部贴图。菜单「贴图与快捷键」也可操作、关闭所有贴图和停用全局快捷键。注册冲突会在菜单提示，菜单操作仍可用。系统安全输入开启或锁屏时，全局快捷键可能暂不可用。
- 屏幕快照在后台并行获取，遮罩和贴图按原尺寸出现，不播放系统缩放动画。框选时复用屏幕图层，只更新遮罩和边框；PNG 编码不阻塞界面。保留原始分辨率及 sRGB 颜色转换。连续截图时只复制最新结果；编码期间在其他应用复制了内容，则保留新的剪贴板内容。
- 沿用 `/Applications/Bento.app` 的屏幕录制权限。截图直接在内存处理，完成截图后自动写入剪贴板，主动保存时才写入文件，不写截图临时文件、不上传。
- 贴图与标注仅保留在当前会话，退出 Bento 后关闭；重要图像请先保存。单张图像限制 4000 万像素。
- 这一版不含 OCR、滚动长截图、取色器、持久历史、文字转贴图或 Snipaste 的全部高级功能。

## 文件夹着色

菜单「文件与文件夹 → 文件夹着色…」选择一个或多个文件夹，再选择红、橙、黄、绿、青、蓝、紫、粉八种颜色。使用 macOS 原生文件夹轮廓，Finder 中直接显示着色后的图标。

- 首次着色前保存原图标；再次着色不覆盖备份。同一磁盘上重命名或移动后仍可恢复。
- 在同一个入口选择「恢复 Bento 着色前的图标」。原本有自定义图标的恢复该图标，原本没有的恢复系统默认。
- 备份存于 `~/Library/Application Support/Bento/FolderIcons`；恢复前请保留此目录。没有备份时不会清除现有图标。
- 只支持可写普通文件夹；不修改文件内容，不对符号链接、应用程序包或无法识别磁盘身份的位置操作。跨磁盘复制后的文件夹不沿用原备份。

## 实时网速

默认在 Bento 顶栏右侧以两行小字显示 ↓ 下载 / ↑ 上传，每秒更新。菜单「显示与连接 → 实时网速」可关闭。

- 统计 `en*` 物理网络接口的字节差值，合计 Wi-Fi 与有线流量；排除 VPN、回环和桥接虚拟接口，避免重复计算。
- B/s 表示字节每秒，K/M/G 按 1024 换算；是设备接口流量，不是互联网测速。
- 首次启动、新接口出现、计数器重置和休眠唤醒时重新取基准，避免瞬间跳出虚假的大数值。

## 大写锁定提示

默认开启视觉与声音提示：Caps Lock 切换时在鼠标所在屏幕显示约 0.8 秒浮层，开启播放 Tink、关闭播放 Purr；开启状态在 Bento 顶栏显示 ⇪。

- 菜单「窗口与输入 → 大写锁定提示」可关闭此功能或仅关闭提示音，设置会保存。
- 浮层不抢输入焦点、不拦鼠标，不影响打字和文件拖动。仅定时读取大小写锁定位，不监听或记录输入内容。
- 启动时读取当前状态，不播放提示音；系统静音时提示音也会静音。

## 滚动方向

macOS 只有一个全局「自然滚动」开关同时管鼠标和触控板。本功能通过事件拦截
把两者解耦,可**分别**把鼠标、触控板设为「自然」或「反转」。

- 下拉菜单里直接有**鼠标**和**触控板**两个左右切换按钮(分段控件):**左=自然,右=反转**
- 默认**鼠标反转、触控板自然**;你的选择存本地,重启后自动恢复
- 会读取系统「自然滚动」作为基准自动换算,改了系统设置也保持正确
- 两个设备都无需翻转时不启用事件拦截。
- 首次启用需授予**辅助功能**权限(事件拦截必需);菜单会引导到系统设置
- 局限:Magic Mouse 上报连续事件,会被当作触控板处理;普通滚轮鼠标正常

> 灵感与技术源自 [fanguolai](https://github.com/chansigit/fanguolai)(CLI 版)。

## Dock 固定

多显示器下 macOS 会让 Dock 跟着鼠标乱跑。本功能把 Dock 固定在你选的那块屏。

- 菜单「Dock 固定」子菜单里选显示器,✓ 标出当前固定在哪块屏;选「关闭」取消固定
- **选中后弹提示**:macOS 没有"直接设定 Dock 在哪块屏"的 API,只能靠指针压向该屏
  Dock 边缘触发。为避免软件替你乱动鼠标,选中目标后会弹一个提示,请你**自己**把
  鼠标移到该屏底部,Dock 就会迁过去;之后固定不再乱跑。目标屏未连接时选中自动跳过
- 源自 [dockpin](https://github.com/chansigit/dockpin)：监听鼠标移动，在非目标屏的 Dock 触发边处把光标移回，减少 Dock 迁移。
- 选择存本地,重启自动恢复
- 用**监听式**全局鼠标监视器和光标回弹实现，不在输入路径中拦截事件，也不需要辅助功能权限；只在接了多块屏且固定了目标时才运行,单屏时完全不跑
- 只拦截**真正的外沿**(边缘外没有其它屏的地方),用 `CGWarpMouseCursorPosition`
  强制把光标挡在 Dock 触发区外;显示器之间的内部边界不拦,不影响跨屏移动
- 插拔显示器会自动重新解析目标屏并调整
- 「Dock 当前在」这行需要屏幕录制权限才能显示,取不到就自动隐藏

## 显示器亮度

菜单「显示器亮度」显示可识别显示器的亮度滑块，松开后写入硬件亮度；外接屏会读回确认是否生效。

- 内建屏:私有 `DisplayServices` 框架读写亮度
- 外接屏:DDC/CI(VCP `0x10`),走 Apple Silicon 的 `IOAVService` I²C 写(与
  m1ddc / MonitorControl 同法);无法读取亮度时显示连接或 DDC/CI 提示；当前仅自动匹配一台外接显示器，多外屏时不猜测对应关系
- 菜单读取显示器当前亮度；无需辅助功能权限。
- 插拔显示器会自动刷新菜单里的显示器列表
- 局限:DDC 并非所有显示器/转接线都支持;部分显示器开 HDR 或 B.I.+ 等图像模式时，可能锁定手动亮度，导致 DDC 写入无效。可在显示器
  OSD 关掉 HDR / 切到 Standard 图像模式,并确保 DDC/CI 为开

## Wi-Fi 信号

菜单「📶 Wi-Fi 信号」子菜单:打开时扫描附近网络,按信号强弱排序显示
每个网络的信号条(▂▄▆█)和 RSSI(dBm),当前连接的网络打 ✓ 并排最前。

- 只在打开该子菜单时才扫描(扫描要占用无线电几秒钟,不会常驻后台扫)
- 同名网络(多个 AP)自动去重,取最强信号
- macOS 要求**定位服务**权限才能显示网络名称;首次打开会请求,拒绝则会提示

## 防止休眠

菜单里的「☕️ 防止休眠」开关:开启后阻止系统休眠和屏幕熄灭(跑长任务、
演示时用),顶栏出现 ☕️ 提示。用 `IOPMAssertion` 实现,无需任何权限。
**不会**跨重启记忆——防休眠是临时状态,重启后自动恢复正常休眠。

## 皮肤与语言

「Bento 设置 → 外观」可选择 **15 款皮肤**，也可以从下拉菜单的「外观」快速切换。包括系统、浅色、深色、抹茶、海盐、蜜柑、樱花、薰衣草、玫瑰、沙丘、薄荷、午夜、极光、余烬、葡萄。皮肤统一控制设置页、窗口切换面板、贴图编辑器的底色、卡片、边框、圆角，以及顶栏、时钟和选中框的强调色；下拉主菜单及级联子菜单使用同一套背景、边框、圆角和悬停／键盘选中效果。不改变截图本身的像素与颜色。窗口切换器仍可单独指定浅色/深色。

语言可在「Bento 设置 → 外观 → 语言」或下拉菜单「语言」切换，支持跟随系统及 **17 种语言**：简体中文、繁体中文、英语、日语、韩语、法语、西班牙语、越南语、瑞典语、俄语、挪威语（Bokmål）、芬兰语、德语、意大利语、乌克兰语、斯瓦西里语、葡萄牙语（巴西）。菜单、设置、截图工具、提示和日期格式随选择更新，不需要重启。选择会跨启动保存；未支持的系统语言按偏好列表匹配，最终回退英语。

- 窗口标题、文件名和用户标注保持原文；内置城市资料保留中文／英文名称。
- 截图工具栏使用紧凑图标，悬停显示当前语言的提示。已有贴图切换语言后保留尺寸、标注、颜色和撤销记录。
- macOS 自带取色器、文件对话框等系统控件仍可能使用系统语言。翻译尚未经过全部语种的母语校对。
- 译文在 `Resources/<语言>.lproj/Localizable.strings`；`Tests/Localization` 检查资源完整性、格式参数和语言匹配。

## 构建与安装(从源码)

先安装 Xcode Command Line Tools，并进入本 README 所在的 `bento/` 目录。以下命令按需要选用：

```sh
./build.sh        # 测试 + 构建 + 安装 + 启动（退出独立 WinTab）
BUILD_ONLY=1 ./build.sh  # 只测试、构建和验证签名，不替换已安装应用
./make-dist.sh    # 测试并打包 DMG，版本取自应用；不替换或重启已安装应用
```

脚本会依次:跑测试 → 编译 → 打包 `Bento.app` → 签名 → 安装到
`/Applications`(不可写时装到 `~/Applications`)→ 启动。安装前备份旧版为 `build/Bento-previous.zip`；若签名身份与已安装 Bento 不一致，拒绝覆盖。

## 使用

下拉菜单分为「世界时钟」「窗口与输入」「截图与贴图」「文件与文件夹」「显示与连接」「Bento」六组。城市时间、鼠标/触控板滚动开关和防止休眠直接可见；外观、登录时启动和设置集中在底部。

菜单支持鼠标悬停展开子菜单、点击执行；↑/↓ 选择，→/← 展开和返回，Enter 确认，Esc 关闭。Tab 可进入亮度滑块等原生控件；菜单过长时可滚动。点击菜单外部或再次点击顶栏按钮关闭菜单。Wi-Fi 扫描结果在当前子菜单中更新；开始截图或 Cmd+Tab 时自动收起菜单。

点击菜单栏的时间(或 🌐)打开菜单:

| 菜单项 | 说明 |
|---|---|
| 城市条目 | 显示该地当前时间与日期;子菜单可 **移除 / 上移 / 下移** |
| 添加城市… | 打开搜索窗口,回车或双击添加,Esc 关闭;本地无结果时回车走在线搜索;同一时区不重复添加 |
| 24 小时制 | 切换 12/24 小时显示 |
| 鼠标滚动 / 触控板滚动 | 鼠标 / 触控板 各自「自然 / 反转」;含系统基准显示与授权入口 |
| Bento 设置… | Bento 的外观、窗口切换控制、权限检查和应用例外；双击 Bento 也可打开 |
| 窗口切换 ▸ | Cmd+Tab 窗口切换、启停、设置、预览与权限状态 |
| Dock 固定 ▸ | 选择把 Dock 固定在哪块显示器;✓ 标出当前;「关闭」取消 |
| 显示器亮度 ▸ | 每块显示器一个亮度滑块(内建走 DisplayServices,外接走 DDC/CI) |
| Wi-Fi 信号 ▸ | 扫描附近网络,显示信号条与 dBm;当前网络打 ✓(需定位权限显示名称) |
| 防止休眠 | 开关:阻止系统休眠与屏幕熄灭;开启时顶栏显示 ☕️;不跨重启记忆 |
| 外观 ▸ | 15 款皮肤，面板底色、卡片、边框、圆角及强调色；选择跨重启记忆 |
| 语言 ▸ | 跟随系统或手动选择 17 种语言，即时更新 Bento 界面 |
| 登录时启动 | 开关 `~/Library/LaunchAgents/com.sijie.gtime.plist` |

### BenQ / 外接显示器亮度

Bento 读取显示器真实亮度和最大值，按实际范围换算百分比；松开滑块后写入并读回确认，不再把发送成功当成调节成功。显示器拒绝时回到实际读数并显示提示。BenQ EW3270U 实测需关闭 HDR / B.I.+、开启 DDC/CI，才能手动调节。连接线/转接器也必须支持 DDC。当前仅自动匹配一台外接显示器，多外屏时不猜测 DDC 对应关系。

图标源文件和生成提示在 `Resources/`。窗口切换功能已集成，无需另装 WinTab；升级时保留 Bento 的签名身份，以延续已授予的权限。
